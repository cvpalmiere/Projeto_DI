Dúvidas rápidas

Preciso pagar para usar?

Não. A Mochila Inteligente é um projeto acadêmico e gratuito.

Onde ficam meus dados?

Nesta versão, no próprio navegador do seu aparelho. Se você limpar os dados do navegador, as contas, matérias e cadernos salvos aqui são apagados.

Esqueci minha senha. E agora?

Esta versão não envia e-mail de recuperação. Crie uma nova conta com outro e-mail para continuar.

O que é a pauta travada?

É uma linha com altura fixa. O texto fica sempre sobre ela e o tamanho da fonte tem um limite para nunca invadir a linha de cima.
